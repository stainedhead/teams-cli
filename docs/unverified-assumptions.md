# Unverified assumptions

Each item is a Graph shape or tenant behaviour that is unconfirmed against a real tenant. Each is carried in code as a comment beginning `ASSUMPTION(unverified against a real tenant): UA-n` and, for Graph shapes, in a test named `TestAssumed...`. Source list: `specs/261003-teams-cli/spec.md` section 9.

How to use this table: "Code reference" and "Test reference" name the code and tests that carry each assumption; they were filled in during Phase I ("none" means no code or test can carry the assumption; only a real tenant settles it). "Verified by" names the M0 spike in `m0-spike-checklist.md` that settles the item. An item stays here until a spike report confirms or refutes it; refuted items move to `requested-core-changes.md` or a spec change.
